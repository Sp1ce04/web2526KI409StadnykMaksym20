# web2526KI409StadnykMaksym20

Лабараторна №3

Апаратне забезпечення: Мікроконтролер ESP32, підключений до потенціометра WH148 через аналоговий пін ADC (GPIO 34) , що використовується для зчитування значень напруги та їх подальшої передачі через Wi-Fi з'єднання.
 
Програмне забезпечення та бібліотеки: Використано бібліотеку ESPAsyncWebServer.h для створення WebSocket-сервера на порті 80 , ArduinoJson.h для формування пакетів даних , а на стороні клієнта застосовано Chart.js для візуалізації отриманих значень у вигляді лінійного графіка в реальному часі.
