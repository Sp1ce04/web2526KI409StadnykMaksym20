# web2526KI409StadnykMaksym20


Лабараторна №2

Апаратне забезпечення: Мікроконтролер ESP32 (модель devkit v1), що виконує роль автономного сервера з підтримкою REST-подібних ендпоінтів, вбудований світлодіод (GPIO 2) для візуалізації стану , а також Flash-пам'ять для зберігання веб-інтерфейсу та USB-кабель для живлення.

Програмне забезпечення та бібліотеки: Використано бібліотеку ArduinoJson.h для обробки JSON-пакетів , LittleFS.h для роботи з файловою системою , WebServer.h для створення API та обробки GET/POST запитів , а також JavaScript із Fetch API на стороні клієнта для асинхронного керування світлодіодом без перезавантаження сторінки.

Лабараторна робота №1

Апаратне забезпечення: Мікроконтролер ESP32 devkit v1 з інтегрованим Wi-Fi модулем для мережевої комунікації, Flash-пам'яттю для розміщення файлів та USB-інтерфейсом для прошивки й енергозабезпечення.

Програмне забезпечення та бібліотеки: Середовище Arduino з використанням HTML/CSS для верстки сторінки, бібліотека LittleFS для адміністрування файлової системи, WiFi.h для стабілізації TCP/IP з'єднання та WebServer.h для менеджменту HTTP-запитів на порту 80
