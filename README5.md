# web2526KI409StadnykMaksym20

Апаратне забезпечення: Мікроконтролер ESP32 (модель WROVER), що виконує роль захищеного вузла (Secure Admin Node), використовуючи обчислювальні ресурси для шифрування трафіку за стандартом AES-256-GCM та Flash-пам'ять для зберігання SSL-сертифікатів.

Програмне забезпечення та бібліотеки: Реалізовано захищене з'єднання HTTPS (порт 443) на базі бібліотеки mbedTLS, впроваджено механізм автентифікації Basic Auth для обмеження доступу до панелі керування, а також використано бібліотеку esp-https-server для реєстрації захищених веб-ресурсів та обробки зашифрованих пакетів.
